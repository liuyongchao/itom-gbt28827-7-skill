# 决策规则速查 — GB/T 28827.7—2022 信息技术服务 运行维护 第7部分：成本度量规范

| 能力 | 一句话规则 |
|---|---|
| 运维范围及六类模型选择 | 按服务内容和对象识别基础环境、硬件、软件、安全、管理、其他运维；安全设备依明示条款路由第9章。 |
| 四类成本归集与有依据的分摊 | 按人员角色、项目归属和适用分章归类；兼职按工作量占比，已定同口径分摊按比例，明确的实际发生项求和。 |
| 四类服务的周期单位工作量 | 按单个对象、同一周期的例行操作、响应支持、优化改善、调研评估分别乘单次工作量和次数后求和。 |
| 基础环境工作量与成本 | 已定参数下逐类计算数量×单位工作量×工作量因子，再按对应单价和价格因子计算直接人力；三类附加成本明确后得总额。 |
| 硬件工作量与成本 | 明确硬件类别与参数后，逐类形成工作量及成本，并归集已核定的其他三类费用。 |
| 软件规模口径与已计量规模调整 | 选择FP或套数口径，接收可追溯外部计数；用已定需求蔓延因子或级别/类型因子计算调整规模。 |
| 软件工作量计算 | 在规模、匹配生产率和三组最终因子均明确时，执行规模×生产率×级别×能力×系统业务特征。 |
| 软件工作量乘综合费率的成本路径 | 仅保留8.2.1：分类工作量×对应综合费率求和，加项目直接非人力成本。 |
| 安全工作量与单类别成本 | 安全分类工作量可汇总；成本仅对整个待测范围确为单类别n=1时执行原式。 |
| 运维管理活动工作量与成本 | 按规划设计、交付管理、质量管控、总结改进四类活动及明确次数/工时/价格计算。 |
| 迁移搬迁的工作分解及成本 | 对适用范围内的迁移、搬迁、云迁移按工作分类与人工要素计算；明示服务级别×地点×批次及人员能力因子位置。 |
| 参数基线与适用证据登记 | 按分章因素名单识别需取证的参数，保留基线、数值、来源、作用层、单位、对象及周期；未知信息列缺口。 |
| 直接非人力及合同周期工具费用 | 按适用分支分项归集项目非人力费用；软件/硬件工具按合同周期已给折旧、管理和其他构成求和。 |
| 成本汇总与口径复核 | 在分项范围、期间、单位、费用层级和已含项已核对后汇总，完整总额与已知小计分别标示。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
