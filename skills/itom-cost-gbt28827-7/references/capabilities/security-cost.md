# 安全工作量与单类别成本

## R — Reading（原文）

> 在计算整体工作量时，分别将以上四类运维服务单独计算后进行汇总，可按照服务目录对服务内容进行相应的裁剪。

来源：GB/T 28827.7—2022，9.3.3.2，印刷 p.16（PDF 第23页）；分类工作量见 9.3.3.1，成本式见 9.2、9.3.1。本卡的单类别费用限制来自对原式疑点的保守处理，原文并未另写此限制。

## I — Interpretation（自述）

安全服务先按安全对象与服务目录分组，单位工作量按四类活动确定。
每类数量、单位工作量及工作量调整因子的乘积是该类工作量。
不同类别的人日可以按同一周期汇总，但工作量可加不意味着费用公式也已澄清。
原安全成本式的求和括号外仍有带类别 i 的单价，存在多类适用范围疑点 S01。
因此本版只在整个待测安全服务范围确为一个类别时计算费用。
多类别仍可输出工作量和费用输入，费用保持待核查；不能逐类另开算例后求和规避限制。
其他三类费用只有明确后才形成完整总成本，缺项始终随结果传递。

## A1 — Application Example（合成演练）

原书未提供该任务的完整案例；以下为合成演练。

一个季度的待测安全范围全部是同一类别的 4 台安全设备，确认每台周期单位工作量 1.5 人日、最终工作量因子 1.2；适用单价为 800 元/人日，价格因子为 1.1。直接非人力、间接人力和间接非人力已核定分别为 300、200、100 元。

`W=4×1.5×1.2=7.2 人日`；直接人力为 `7.2×800×1.1=6,336 元`；该范围完整服务成本为 `6,336+300+200+100=6,936 元`。如果待测范围还有另一类设备，先并入真实范围清单，费用转为 S01 待核查，不能保留“全范围 n=1”的声明。

## A2 — Future Trigger（触发与邻接）

- 为防火墙等安全对象或安全服务估工作量：“安全运维测算 / security maintenance effort”。
- 已有分类对象、单位人日与因子，要算分类及总工作量：“安全设备多少人日 / security workload”。
- 整个待测范围只有一个类别且价格明确，要计算费用：“单类安全服务成本 / single-category security cost”。
- 要复核多类别安全报价是否可直接套式：“安全分类单价怎么求和 / security price summation”。

相邻区分：安全设备不因硬件外形转到 hardware-cost。unit-workload 产生单对象周期工时，本卡接收它再乘对象数量。parameter-evidence 登记安全工作量与价格层参数；total-review 不得将本卡多类待核查项拼成完整总价。

## E — Execution（执行契约）

**输入。** 整个待测安全服务范围、周期、对象分类依据；每类数量 `N_i`、单位工作量 `U_i`（人日/对象/周期）、最终工作量因子 `Kwi` 及证据。请求费用还需真实全范围类别数、单类别证明、单价 `P`（元/人日）、最终价格因子 `Kp`、币种、直接非人力 `DN`、间接人力 `IL`、间接非人力 `IN` 的数值及完整性。

**输出。** 真实范围清单、分类工作量表、可比工作量合计；费用分支满足条件时给直接人力与总额/已知小计，不满足时明确 `N01 / S01：多类别安全费用待核查`，不得出现据本标准自动计算的多类别费用总值。已知其他费用可以单列，不能将其称为安全服务总成本。

1. 先固定范围和分类。查看请求是否本来含多个安全类别，拒绝通过临时拆单或改名把它们视作各自独立 n=1。完成标准：全范围类别清单完整，有明确对象与活动边界。
2. 计算每类 `W_i=N_i×U_i×Kwi`，再对同一周期、同一工时单位的结果求 `W=ΣW_i`。若单位工作量未形成，转 unit-workload；因子缺失转 parameter-evidence。完成标准：分类行能复算，单位为人日，未重复乘数量。
3. 判断费用分支。整个范围类别数不等于 1、分类不明、或用户要求拆单后汇总时停止费用计算，传递 S01；各类同价也不启用本版的多类扩展。完成标准：停止原因与仍可使用的工作量清晰分开。
4. 仅在真实 n=1 且价格依据完整时计算 `DL=W_1×P×Kp`。费用完备时 `C=DL+DN+IL+IN`；某项未知则只报已知小计和缺口。各已确认为零的项单独标零。先读 CALCULATOR.md，构造 `security` 模式 JSON 并如实填写整个范围的 `scope_size`，数值用十进制字符串，运行 `python resources/itom_calc.py input.json --out output.json`。不能将单次脚本输入行数冒充真实范围类别数。
5. 附范围、参数依据、单位和状态。实现约定：中间不提前取整；最终金额按项目精度或默认显示到分，保留未舍入值。完成标准：费用结果可追溯到真实单类别范围，缺口及 S01 未被下游汇总抹去。

## B — Boundary（边界）

**来源边界。** 安全成本原式疑点不等于工作量公式无效；本版保留明确部分，不擅自将分类单价搬进求和括号。全范围多类别异价、同价及拆单后汇总均暂不执行费用路径。安全等级、工具、风险等因素没有全书通用系数或内部合成法；仅接收有依据的最终因子。

**工程校验。** 数量与工时不得负数或非有限；同一分类不得重复，单位与周期必须一致。工具使用日不算人员人日，未知费用不算零。需要复核分组来源，不得通过把所有类别重命名为“安全设备”绕过来源限制。

**关系。** 范围不明转 scope-routing；单位工作量转 unit-workload；缺参数转 parameter-evidence；完整性及 S01 状态随结果交 total-review。
